# Project Vending Machines

Система учета и управления торговыми автоматами.  
Проект включает backend API, desktop-клиент и web-клиент.

Проект разрабатывался для подготовки к чемпионату профессионалы 2026 с акцентом на архитектуру, работу с БД и клиент-серверное взаимодействие.

---

## Стек технологий

### Backend
- C#
- ASP.NET Core
- Entity Framework Core
- JWT авторизация
- REST API

### Database
- SQL Server

### Desktop
- WPF (.NET)

### Frontend
- Vue 3
- Vite
- Axios

---

## Архитектура проекта

Проект состоит из трех основных модулей:

- `VendingMachines.Api`  
  Web API сервер, отвечает за бизнес-логику, авторизацию и работу с БД.

- `VendingMachines.Desktop`  
  Desktop-приложение на WPF для администрирования системы.

- `VendingMachines.Web`  
  Web-клиент для работы через браузер.

---

## Основной функционал

- Регистрация и авторизация пользователей (JWT)
- Роли пользователей
- CRUD операции для сущностей
- Работа с БД через EF Core
- Клиент-серверное взаимодействие
- Валидация данных
- Обработка ошибок API
